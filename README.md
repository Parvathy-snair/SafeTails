# 🐾 SafeTails – Animal Rescue & Welfare Platform

**SafeTails** is a web-based animal rescue and welfare platform developed using React.js. It aims to support animal welfare initiatives by providing a space where users can submit animal rescue requests, explore rescue activities, and contribute towards animal welfare through donations.

The platform focuses on creating awareness about animal rescue and making it easier for people to participate in helping animals in need.

## ✨ Features

- **User Authentication:** User registration and login functionality.
- **Rescue Requests:** Allows users to submit animal rescue requests.
- **Donation Page:** Supports INR and USD currency selection with multiple donation options.
- **Animated Statistics:** Displays rescue-related statistics with animated counters.
- **Responsive Design:** User-friendly interface adaptable to different screen sizes.
- **Animal Welfare Information:** Dedicated sections highlighting animal rescue and sanctuary activities.
- **REST API Integration:** Connects the frontend with the backend to manage application data.
- **CRUD Operations:** Supports creating, reading, updating, and deleting application records.

## ⚙️ Installation & Setup

Follow these steps to run SafeTails locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd SafeTails
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure the API**

Update the Axios base URL in your API configuration file to point to your backend server.

For local development:

```js
baseURL: "http://localhost:4000"
```

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

**Note:** The backend JSON Server must also be running on the configured port for API-dependent features to work.
